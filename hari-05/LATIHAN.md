# Latihan Hari 5

## Mudah — Daftar pendek
**Instruksi:** Tampilkan tiga topik dengan `map()`.
**Kriteria:** Semua item muncul dan memiliki key.
**Petunjuk:** Gunakan array string atau object.

## Menengah — FlatList objek
**Instruksi:** Render array object berisi id dan judul memakai `FlatList`.
**Kriteria:** Key berasal dari id; judul ditampilkan.
**Petunjuk:** `renderItem` menerima object yang memiliki properti `item`.

## Menantang — Bandingkan daftar
**Instruksi:** Buat daftar kecil dengan `ScrollView` dan ubah menjadi `FlatList`.
Jelaskan kapan pilihan kedua lebih tepat.
**Kriteria:** Perilaku dan identitas item tetap benar.
**Petunjuk:** Fokus pada jumlah item dan rendering virtual.
