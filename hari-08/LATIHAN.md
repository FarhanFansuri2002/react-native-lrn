# Latihan Hari 8

## Mudah — Input nama
**Instruksi:** Buat `TextInput` yang nilai ketikannya terlihat di `Text`.
**Kriteria:** Tampilan berubah untuk tiap ketikan.
**Petunjuk:** Hubungkan `value` dan `onChangeText`.

## Menengah — Formulir sapaan
**Instruksi:** Tambahkan tombol yang menampilkan sapaan dari input.
**Kriteria:** Spasi/masukan kosong ditangani dengan wajar.
**Petunjuk:** String dapat dibersihkan dengan `trim()`.

## Menantang — Tambah catatan
**Instruksi:** Buat input judul dan tambahkan catatan ke daftar ketika tombol ditekan.
**Kriteria:** Input dikosongkan setelah berhasil dan data tersimpan sebagai state array.
**Petunjuk:** Buat salinan array baru ketika menambah item.
