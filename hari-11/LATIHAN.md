# Latihan Hari 11

## Mudah — Tampilkan judul
**Instruksi:** Ambil field berbeda dari response JSON.
**Kriteria:** Nilai ditampilkan setelah request berhasil.
**Petunjuk:** Lihat object hasil `response.json()`.

## Menengah — UI tiga status
**Instruksi:** Tampilkan loading, data, dan error secara terpisah.
**Kriteria:** Respons HTTP gagal diperiksa dan error tidak disembunyikan.
**Petunjuk:** Gunakan object state dengan status yang jelas.

## Menantang — Retry
**Instruksi:** Tambahkan tombol untuk mencoba request kembali setelah gagal.
**Kriteria:** Status loading kembali terlihat dan aksi retry dapat diuji.
**Petunjuk:** Pisahkan fungsi `muat` dan picu ulang saat tombol ditekan.
