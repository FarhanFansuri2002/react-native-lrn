# Latihan Hari 7

## Mudah — Penghitung
**Instruksi:** Buat angka dan tombol tambah menggunakan `Pressable`.
**Kriteria:** Angka berubah lewat setter state.
**Petunjuk:** Awali `useState` dengan nol.

## Menengah — Batas minimum
**Instruksi:** Tambahkan tombol kurangi tetapi jangan izinkan angka kurang dari nol.
**Kriteria:** Nilai selalu nol atau lebih.
**Petunjuk:** Periksa nilai sebelum mengurangi.

## Menantang — Toggle favorit
**Instruksi:** Buat tombol favorit yang mengubah label dan status ikon/teks.
**Kriteria:** UI selalu mengikuti boolean state.
**Petunjuk:** State awal boolean; satu tap membalik nilainya.
