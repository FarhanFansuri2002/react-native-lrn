# React Native Learning

Proyek belajar React Native basic selama 14 hari menggunakan Expo. Satu
instalasi menjalankan seluruh contoh; pilih hari dengan tombol di bagian atas.
Setiap latihan tetap milik Anda dan tidak ditandai selesai otomatis.

## Menyiapkan perangkat

1. Pasang Node.js versi LTS.
2. Pasang aplikasi **Expo Go** di ponsel Android/iOS, atau siapkan emulator.
3. Buka terminal PowerShell di folder `react-native-learning`.
4. Jalankan `npm.cmd install` satu kali.
5. Jalankan `npm.cmd start`.
6. Pindai QR code dengan Expo Go, atau tekan `a` untuk Android emulator / `i`
   untuk iOS Simulator (iOS Simulator memerlukan macOS).

Simpan perubahan untuk melihat pembaruan. Tekan `Ctrl+C` untuk menghentikan
server. Jika perangkat tidak tersambung ke jaringan yang sama, gunakan opsi
tunnel Expo dari menu terminal.

## Cara belajar

1. Baca `PETA_BELAJAR.md`, lalu materi hari yang dipelajari.
2. Coba contoh lewat aplikasi dan ubah satu bagian untuk mengamati hasil.
3. Kerjakan latihan; lihat petunjuk setelah mencoba sendiri.
4. Jawab lima pertanyaan kuis tanpa kunci jawaban.
5. Isi refleksi dan catat progres secara manual.

Folder `hari-XX` berisi materi, latihan, kuis, refleksi, dan contoh `App.jsx`.
`src/App.js` menjadi pemilih contoh; proyek Expo tidak dibuat ulang per hari.

## Web

Proyek ini difokuskan untuk Android/iOS melalui Expo Go. Dukungan web belum
diaktifkan agar konfigurasi tetap sederhana dan komponen yang dipelajari
memang berorientasi perangkat mobile.
