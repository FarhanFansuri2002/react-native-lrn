# Latihan Hari 2

## Mudah — Komponen judul

**Instruksi:** Buat component `JudulBelajar` yang menampilkan judul dan
deskripsi, lalu gunakan di component utama.

**Kriteria keberhasilan:** Nama component kapital dan hasilnya terlihat.

**Petunjuk:** Pindahkan teks terkait ke function component terpisah.

## Menengah — Kartu reusable

**Instruksi:** Buat `KartuMateri` dan tampilkan tiga kali untuk tiga topik.

**Kriteria keberhasilan:** Bentuk kartu dibuat sekali dan digunakan tiga kali.

**Petunjuk:** Untuk saat ini teks boleh sama; variasi data dipelajari lewat props.

## Menantang — Susun layar profil

**Instruksi:** Buat bagian header profil, ringkasan, dan target belajar.
Tentukan component mana yang perlu dipisah.

**Kriteria keberhasilan:** Component utama mudah dibaca; pemisahan dilakukan
berdasarkan peran UI, bukan setiap elemen kecil.

**Petunjuk:** Gambar pohon component sebelum menulis JSX.
